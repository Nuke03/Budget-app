# Il Libretto, ultimo pezzo: annulla, pagine rimaste, icone, icona dell'app (piano B3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** chiudere il blocco 2 della ROADMAP.
- Ogni eliminazione si può annullare per qualche secondo; quelle pesanti chiedono prima conferma.
- Storico, obiettivi, conti, categorie e P.IVA passano nel mondo "Il Libretto".
- I caratteri `›` e `‹` diventano icone vere.
- L'app ha un'icona sua.

**Architecture:**
- **Annullamento:**
  - Un solo meccanismo, l'"eliminazione rimandata": la riga sparisce subito dall'interfaccia, in basso compare un avviso con "Annulla" per 5 secondi, e solo allo scadere parte la scrittura vera.
  - La scrittura è sempre l'operazione di oggi, compreso l'aggiornamento del saldo.
  - Chiudere la pagina o cambiare pagina prima dello scadere fa partire subito la scrittura (`pagehide` e smontaggio), così nessuna eliminazione si perde.
  - Annullare non tocca il database, quindi non c'è niente da rimettere a posto.
- **Icone:** `lucide-react`, già nel progetto.
- **Icona dell'app:** generata con le convenzioni di Next, cioè `app/icon.tsx`, `app/apple-icon.tsx` con `ImageResponse` e `app/manifest.ts`. Nessuno strumento per le immagini, nessun file raster scritto a mano.

**Tech Stack:** Next.js 16.3.3, React 19, Tailwind 4, `lucide-react`, vitest.

**Spec:**
- `docs/ROADMAP.md`, blocco 2 ("Eliminazioni con annullamento", "Icona dell'app");
- `DESIGN.md`, che è il sistema da seguire;
- `PRODUCT.md`.

- **Soldi:** l'eliminazione rimandata non cambia nessun calcolo. La scrittura finale è esattamente quella di oggi, con il saldo aggiornato nello stesso punto del codice.
- **Nessuna migrazione.**

## Review Focus

### Task 1: il meccanismo dell'eliminazione rimandata

**Files:**
- Create: `src/lib/eliminazioneRimandata.ts` (logica pura, senza React)
- Create: `src/app/AvvisoAnnulla.tsx` (avviso in basso) e `src/app/AnnullaProvider.tsx` (contesto montato in `layout.tsx`)
- Modify: `src/app/layout.tsx`
- Test: `tests/eliminazioneRimandata.test.ts`, `tests/AvvisoAnnulla.test.tsx`

**Interfaces:**
- Produces:

```ts
export interface Rimandata { id: string; testo: string; esegui: () => Promise<void>; }
export function creaCodaRimandata(opts: { attesaMs: number; setTimer?: typeof setTimeout; clearTimer?: typeof clearTimeout }): {
  aggiungi(r: Rimandata): void;          // se ce n'è già una in attesa, la esegue subito e la sostituisce
  annulla(id: string): boolean;          // true se annullata prima dell'esecuzione
  eseguiTutte(): Promise<void>;          // per pagehide e smontaggio
  inAttesa(): Rimandata | null;
};
// React
export function useEliminaConAnnulla(): (r: { id: string; testo: string; esegui: () => Promise<void>; nascondi: () => void; ripristina: () => void }) => void;
```

**Regole:**
- `attesaMs` vale 5000.
- **Avviso:** in basso, sopra la barra, con `role="status"` e `aria-live="polite"`. Testo per esempio "Spesa eliminata.", poi il pulsante "Annulla" (almeno 44 px), poi la chiusura.
- **Stile:** `bg-foreground` con `text-background`, oppure la superficie scura del tema. Deve passare AA in chiaro e in scuro.
- **Errore nella scrittura finale:** la riga viene ripristinata (`ripristina`) e l'avviso dice "Non sono riuscito a eliminarla: riprova."
- **`pagehide` e `visibilitychange` su `hidden`:** chiamano `eseguiTutte()`.

- [ ] **Step 1: test.**
  - `esegui` parte dopo 5 s;
  - `annulla` prima dei 5 s non esegue;
  - una seconda `aggiungi` esegue subito la prima;
  - `eseguiTutte` esegue quella in attesa una sola volta;
  - un errore chiama `ripristina`;
  - l'avviso mostra testo e "Annulla", e il clic annulla.
- [ ] **Step 2:** eseguire i test. Atteso: FAIL.
- [ ] **Steps 3-4:** implementare, poi i test e `tsc`. Atteso: PASS.
- [ ] **Step 5:** commit e push (`feat: eliminazioni con annullamento, il meccanismo`). Revisione con sonnet.
